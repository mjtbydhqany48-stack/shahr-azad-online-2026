# سرور چندنفره شهر آزاد 3D

این بسته سرور Socket.IO مورد انتظار نسخه HTML فعلی بازی را فراهم می‌کند.

## قابلیت‌ها
- پنج اتاق رسمی: `server-1` تا `server-5`
- حداکثر ۲۰ اتصال هم‌زمان در هر اتاق
- دریافت و پخش موقعیت بازیکنان، جهت، حالت پیاده/ماشین/موتور و اسکین
- نمایش تعداد بازیکنان اتاق
- رد کردن ورود به اتاق پر یا نامعتبر

## اجرا روی سرویس میزبانی Node.js
1. این ZIP را از حالت فشرده خارج کن.
2. پوشه را در یک مخزن خصوصی GitHub قرار بده (یا از روش بارگذاری مستقیم سرویس میزبان استفاده کن).
3. در سرویس میزبانی Node.js یک Web Service جدید بساز و مخزن را متصل کن.
4. دستور نصب: `npm install`
5. دستور اجرا: `npm start`
6. پس از انتشار، آدرس HTTPS سرویس را بردار؛ مثلاً `https://your-service.example`.

## نکته مهم
- این کد کلید API یا رمز عبور لازم ندارد؛ هیچ کلید محرمانه‌ای را داخل APK قرار نده.
- فعلاً Appwrite برای این ارتباط زنده ضروری نیست؛ کلاینت بازی فعلی از Socket.IO استفاده می‌کند.
- این سرور یک نمونه اولیه است. قبل از انتشار عمومی باید احراز هویت، محدودسازی نرخ پیام‌ها، ذخیره امن حساب‌ها و نظارت اضافه شود.
- برای تست، ابتدا دو گوشی را به یک `SERVER` وصل کن. ظرفیت ۲۰ نفر برای هر سرور در این نسخه اعمال شده است.
